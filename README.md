# ARKFGF 联机助手

加入《方舟：生存进化》（ASE）和《方舟：生存飞升》（ASA）没有公网 IP 的服务器。

---

## 这是什么

部分服主没有公网 IP，玩家没法直接用 IP 进服。联机助手用 P2P 打洞在你和服务器之间建立直连，就像两台电脑直接通信，流量不经过任何中间服务器。

**[arkfgf.com/link](https://arkfgf.com/link)** — 介绍页  
**[arkfgf.com/rooms](https://arkfgf.com/rooms)** — 联机大厅（找房间）  
**[arkfgf.com/download](https://arkfgf.com/download)** — 下载

---

## 怎么用

**找到房间，进服：**

1. 在 [联机大厅](https://arkfgf.com/rooms) 找一个房间，或者直接在网站房间页点「用联机助手加入」唤起助手
2. 用 Steam 登录：开着 Steam 客户端时会弹出 Steam 窗口，点「登录」即可；没开 Steam 时在浏览器里登录。助手拿不到你的密码
3. 点「加入」，等助手显示「已直连」，再点「进入游戏」——助手把服务器加入 Steam 收藏并启动 ARK
4. 在游戏主菜单点「加入方舟」，切到「收藏」，选这台服务器加入

也可以自己在 Steam 的「查看 → 游戏服务器 → 收藏」里添加助手显示的地址（通常是 `127.0.0.1:27015`），再从游戏里的收藏列表加入。注意要从**游戏里**的列表加入：在 Steam 的收藏窗口里直接点「连接」会报 "Unable to query server info for invite"，ARK 服务器不支持这种方式。

**ASA（生存飞升）服务器**：房间里标着「ASA」的服务器不能从 Steam 收藏或游戏里的服务器列表进入，助手也不会显示「进入游戏」。等助手显示「已直连」后，点「复制命令」复制助手显示的命令（例如 `open 127.0.0.1:7777`），打开 ASA，在主菜单按 Tab 打开控制台，粘贴后回车即可进服。一个房间里可以同时有 ASE 和 ASA 服务器，加入一次就都能连。

本机的 7777、7778、27015 等端口被别的程序占用时，助手会自动换成别的端口，不影响进服（ASA 服务器按助手显示的命令里的端口进服）。

## 游戏工具

顶栏「游戏工具」里有两个工具，不用加入房间也能用：

**画质**：一键档位或者逐项勾选，每一项都写了副作用，展开「参数」能看到实际改了什么。

- ASE（生存进化）：写进游戏目录的 `Engine\Config\BaseDeviceProfiles.ini`，下次启动游戏时生效。第一次生效前自动备份原文件（同目录的 `BaseDeviceProfiles.ini.arkfgf-backup`，游戏更新或验证文件覆盖了原文件后，下次生效时重新备份）。「去掉助手的修改」只删除助手写入的那一段；「恢复原文件」用备份整份覆盖回去
- ASE 也可以选「控制台命令」：不改文件，进游戏按 Tab 粘贴执行，重启游戏恢复默认。只读参数（自动曝光等）和除雾、去除水面和树叶只能写进 ini，选了也不会出现在命令里。这种方式还没有逐条实测，标为实验性
- ASA（生存飞升）：生成控制台命令，进游戏按 Tab 打开控制台粘贴执行，重启游戏恢复默认
- 「去除水下致盲」会让泰克头盔等透视 / 扫描能力失效；标了「实验性」的项在部分游戏版本上可能无效
- 伽马：ASE、ASA 都在控制台输入 `gamma <数值>`

**连点器**：按热键（默认 F8，可选 F5–F12）开关，连续点击鼠标左键 / 右键 / 键盘按键，或者一直按住。默认只在 ARK 窗口在前台时点击，切出游戏自动暂停、松开按住的键。

画质参数和连点器都只作用于你自己的电脑。服务器有自己的规则，使用前请确认服务器允许。

## 注意事项

**网络要求**：P2P 直连要两边的网络能打洞。大多数家用宽带没问题。部分公司网、校园网或严格的移动热点可能打不通——助手会明确提示，不会假装连上了。连不上时可以换个网络试试，或者问服主有没有公网 IP 的备用方案。

**只支持 Windows 10 / 11 64 位**，开源免费。

**杀毒软件提示**：安装包还没有代码签名，Windows Defender 或 SmartScreen 可能误报或拦截。新发布的版本都附带 GitHub 的构建证明，可以用 GitHub CLI 验证文件确实来自本仓库的 CI 构建：`gh attestation verify 文件名 -R TBro1998/ArkServerLink`。也可以先用便携版。

## 自动更新

安装版在启动时检查新版本，顶栏出现「新版本 vX.X」提示时点一下就能更新。国内下载慢可以在更新对话框里换一条加速线路，默认会自动测速选最快的。

## 接口地址（开发用）

助手调用 arkfgf.com 的两组接口：Steam 登录在 `https://arkfgf.com/api/v1`，联机大厅（房间列表、加入房间、检查新版本）在 `https://link.arkfgf.com/api/v1`。本地联调时可以用环境变量改：

- `ARKFGF_API`：Steam 登录的接口地址。设置了而没有设置 `ARKFGF_LINK_API` 时，联机大厅也用这个地址（一个本地网站提供所有接口）
- `ARKFGF_LINK_API`：联机大厅的接口地址
